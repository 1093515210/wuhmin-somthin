关于哈德逊研究所<p>
哈德逊研究所是一家研究机构，致力于提升美国在安全、自由和繁荣未来的领导地位。<p>
哈德逊研究所由战略家赫尔曼•卡恩于1961年创立，挑战传统思维，并通过在国防、国际关系、经济、能源、技术、文化和法律等领域的跨学科研究，帮助管理面向未来的战略转型。<p>
哈德逊研究所致力于通过一系列出版物、会议、政策简报和建议，为政府和企业的政策制定者和全球领导者提供指导。<p>
