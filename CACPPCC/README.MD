<P>#共產主義後的中國：為後中共時代的中國做準備
<P>##关于作者
<P>###余茂春
<P>余茂春是哈德逊研究所中国中心的高级研究员兼主任。他同时也是美国海军学院（位于马里兰州安纳波利斯）东亚史和军事史/海军史教授。余博士专攻中国军事和战略文化、中美军事和外交史以及美国对华政策。
<P>余博士曾加入特朗普政府，担任国务卿迈克•蓬佩奥的中国政策顾问。在此期间，他为蓬佩奥就所有涉华问题提供建议，协助调整美国对华政策，并参与美国政府各部门就涉及中国及其他东亚国家（包括日本、韩国和台湾）的重大政策和政府行动进行的关键磋商。他还是印太安全研究所的高级研究员，以及胡佛研究所军事史/当代冲突工作组成员。 2011年至2016年，他为《华盛顿时报》撰写每周专栏“中国内幕”（Inside China），目前为该报撰写双周专栏“红色地平线”（Red Horizon）。他还在哈德逊研究所主持每周播客节目“中国内幕”（China Insider）。自1996年以来，他一直是自由亚洲电台的编辑顾问，并为包括《华尔街日报》和PBS新闻一小时在内的多家媒体撰稿。
<P>余博士拥有加州大学伯克利分校历史学博士学位、斯沃斯莫尔学院硕士学位和南开大学学士学位。
